# AquaPulse — Frontend

This folder contains the client application built with React, TypeScript, Vite, and Tailwind CSS.

Run locally:

1. cd client
2. npm install
3. npm run dev

Notes:
- The frontend is designed to work with a backend at /api but includes demo behaviors (demo login and localStorage-based hydration) for showcasing the UI without a backend.
